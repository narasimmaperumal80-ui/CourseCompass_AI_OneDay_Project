# Data documentation

`courses.csv`: course metadata and subject-alignment weights.

`resources.csv`: structured curated learning-resource links used by the application.

`student_data.csv`: generated automatically by `train_recommendation.py`. SYNTHETIC DEMO DATA.

`demand_data.csv`: generated automatically by `train_demand.py`. SYNTHETIC DEMO/TREND DATA.

Do not describe the generated datasets as real-world observations in an academic report.
